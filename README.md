## Running Experiment 10

1. Open Terminal in the `backend` directory.
2. Install dependencies using `npm install`.
3. Create a `.env` file based on `.env.example`.
4. Add your MongoDB connection string to `MONGODB_URI`.
5. Start the backend using `npm start`.
6. Open http://localhost:3000/exp10.html.

Experiment 10 requires the Node.js backend and MongoDB connection. GitHub Pages cannot run the backend.

## Project Structure

The root directory contains the ten experiment HTML files and the supporting images. The `backend` directory contains the Node.js and MongoDB implementation for Experiment 10.

## Security

Database credentials are stored locally in `backend/.env` and are excluded from version control.
